# MinutiaeNet (PyTorch)

MinutiaeNet is a fully automatic minutiae extractor based on deep neural networks with compact feature representation for fast comparison of minutiae sets. It integrates deep networks and fingerprint domain knowledge for robust extraction, particularly on latent and poor-quality plain fingerprints.

This repository contains the **refactored PyTorch implementation** of MinutiaeNet (originally written in Keras/TensorFlow for Python 2.7).

## Architecture
The framework exploits fingerprint domain knowledge encoded within deep neural networks:
1. **CoarseNet**: A residual learning-based CNN that takes a fingerprint image and estimates the minutiae score map, orientation field, segmentation map, and enhanced image.
2. **FineNet**: A robust Inception-Resnet based minutiae classifier that refines candidate minutiae patches based on the score map generated by CoarseNet.

## New Additions & Capabilities
The original codebase has been modernized to provide greater flexibility, performance, and ease of use:
- **PyTorch Port:** The original `.h5` models have been modularly refactored and converted to PyTorch `.pth` models, running on modern Python 3.1x.
- **Python API:** A clean API (`minutiaenet.api.run_inference`) is provided for seamless integration into custom Python scripts.
- **Multi-GPU Command Line Interface (CLI):** Support for large-scale batch extractions utilizing Distributed Data Parallelism (DDP) for maximum throughput across multiple GPUs.
- **Enhanced Visualization:** Included robust plotting utilities in `minutiaenet.plot` to visualize the orientation field, enhanced image, and detected minutiae.

## Usage

### 1. Command Line Interface (CLI)
The CLI allows you to easily process single images, directories, or a list of images using one or multiple GPUs.

**Basic Inference:**
```bash
minutiaenet infer /path/to/input.png /path/to/output_dir
```

**Large-scale Multi-GPU Batch Extraction:**
Extract minutiae from an entire directory recursively, using 4 GPUs, with a batch size of 8 per GPU:
```bash
minutiaenet infer /path/to/dataset/ /path/to/output_dir/ --gpus 4 --batch-size 8 --recursive
```

**Use FineNet Refinement:**
```bash
minutiaenet infer /path/to/input.png /path/to/output_dir --finenet
```

**Visualize Results:**
Read the generated outputs resulting from the extraction and plot the views:
```bash
minutiaenet plot /path/to/output_dir/ input.png --save output_plot.png
```

### 2. Python API
You can run the model directly from Python by importing `minutiaenet.api`.

```python
from minutiaenet.api import run_inference

# Run inference on a directory or image
run_inference(
    input_path="/path/to/dataset",
    output_path="/path/to/output_dir",
    gpus=1,             # Use 1 GPU (or a list like [0, 1] for specific GPUs)
    batch_size=4,       # Batch size per GPU
    recursive=True,     # Process subdirectories
    mnt_degrees=True,   # Save angles in degrees instead of radians
    quality_mask=True,  # Generate continuous quality masks
    use_finenet=True    # Use FineNet to verify patches
)
```
